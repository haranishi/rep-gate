# RepGate（仮称）

設定した時刻になるとゲートが閉じ、カメラの前で腹筋・腕立て・スクワットをすると解除される。判定はブラウザ内で完結し、**映像は端末から出ない**。

これは製品ではなく **PoC** です。Obsidian の要件定義書（`02_notes/20_事業・経営/事業グロース/運動ロック解除_WebPoC_要件定義書.md`）と、調査本体（`2026-07-22_運動でロック解除するスマホ依存対策アプリ.md`）が対になっています。

## いちばん大事な制約

**このWebアプリは実際にスマホをロックできません。** ブラウザには他アプリを起動・停止する権限がないためです。ここで閉じるのはこのページだけです。

実ロックには iOS の Family Controls（Swift＋Appleの手動審査が要る entitlement）が必要で、ネイティブ版の仕事になります。本PoCの目的は、その前に**判定精度とUXだけを先に確かめること**です。

## このPoCで確かめること

| # | 仮説 | 見るところ |
|---|---|---|
| H1 | 顔が見えなくても姿勢推定が動くか | 腹筋・腕立てで顔が床を向いたときにカウントが続くか |
| H2 | ユーザーが自然に置くカメラ位置でも数えられるか | 床置き正面と斜め45°で、手で数えた回数とどれだけずれるか |
| H3 | SNSに出したくなる成果物が作れるか | リザルト画像を実際に投稿する気になるか |

H2 の比較には、記録画面の「計測ログを書き出す」で出る CSV（1レップごとの所要時間と角度の振れ幅）を使ってください。

## 動かし方

カメラは HTTPS か localhost でしか使えません。

```bash
cd ~/Projects/rep-gate
python3 -m http.server 8777 --bind 127.0.0.1
# http://127.0.0.1:8777/ を開く
```

スマホの実機で試すときは、同じLANのPCで立てたサーバーに `http://` で入ってもカメラは動きません。HTTPS のトンネル（Cloudflare Tunnel など）か、静的ホスティングへ上げてください。

## 判定のしくみ

MediaPipe Pose Landmarker（`pose_landmarker_lite`）を WASM で動かし、3点のなす角から回数を数えます。

| 種目 | 測る角 | 縮んだ状態 | 伸びた状態 | 追加条件 |
|---|---|---:|---:|---|
| 腹筋 | 肩–腰–膝 | 95°未満 | 130°超 | — |
| 腕立て | 肩–肘–手首 | 100°未満 | 150°超 | 胴体（肩–腰–膝）が150°超 |
| スクワット | 腰–膝–足首 | 100°未満 | 160°超 | — |

**伸びきり → 縮みきり → 伸びきり**を通過して1回。上下のしきい値を両方越えないと数えないので、半端な可動域は原理的に加算されません。加えて **1レップ0.8秒未満は無効**（勢いだけのごまかし対策）。

左右は関節の見えやすい側を自動で選びます（横向きに寝る腹筋では片側しか映らないため）。角度は `worldLandmarks`（3次元）で計算するので、画角の縦横比に影響されません。

**開始前チェック**：必要な関節がすべて信頼度0.6以上で1.5秒続くまで、開始ボタンを押せません。調査で「床に正面置きだと一致率20〜37%まで落ちる」と分かっているため、ここは意図的に厳しくしています。

## 素材について

競合アプリのアイコン・イラスト・文言は一切使っていません。

- アプリアイコン（`assets/icon.png`）は Codex で生成した自前の画像
- リザルト画像は canvas に図形と文字で描いており、画像素材を使っていません

## 構成

```
index.html      全画面のマークアップ
styles.css
js/pose.js      MediaPipe の読み込みと角度計算
js/exercises.js 種目定義とレップ判定の状態機械
js/store.js     端末内の保存（設定・記録・解除状態）
js/result.js    リザルト画像の描画と共有
js/main.js      画面遷移・カメラ・計測ループ・ゲート判定
assets/icon.png
```

依存パッケージはありません。ビルド不要。MediaPipe だけ CDN から読み込みます。

## テスト

`tests/test-repgate.mjs` に26項目（判定ロジック・画面遷移・ゲート・リザルト画像・カメラ起動）。Playwright は kenkyuu-app の node_modules を借ります。

```bash
python3 -m http.server 8777 --bind 127.0.0.1   # サーバーを立ててから
node tests/test-repgate.mjs                     # スクショは tests/output/ に出る
```

## SNS共有について

Web から Instagram や X へ**直接投稿することはできません**（Instagram の公開APIはプロアカウント限定、X の投稿APIは実質有料）。そのため「投稿する」のではなく、**共有シートに画像を渡す**形にしています。
